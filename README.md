## Getting started

1. Install a current version of Node.js and npm.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Build for production:

   ```bash
   npm run build
   ```

Confirm available scripts in `package.json` before running them.
